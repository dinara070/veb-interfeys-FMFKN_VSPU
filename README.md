# veb-interfeys-FMFKN_VSPU

Система управління навчальним процесом (LMS) для ФМФКН

Це веб-інтерфейс, розроблений для автоматизації роботи деканату та взаємодії між викладачами й студентами. Проєкт побудований на базі Python з використанням бібліотеки Streamlit.

Основний функціонал:
- Аналітика та статистика: Моніторинг кількості студентів, завантажених матеріалів та середнього бала.
- Управління контингентом: База даних студентів та груп з можливістю імпорту/експорту через CSV.
- Навчальний процес: Електронний журнал оцінок, облік відвідуваності та розклад занять.
- Документообіг: Система подання та обробки заяв, генерація довідок та академічних відомостей.
- Модулі деканату: Управління поселенням у гуртожиток, розрахунок стипендій та робота з контрактами.
- Сесія: Генерація екзаменаційних відомостей та автоматизація переведення на наступний курс.

Системні налаштування та безпека: Проєкт включає розширену панель адміністрування, яка дозволяє керувати правами доступу користувачів (Admin, Teacher, Student). Вбудована система Audit Log (Журнал дій) фіксує кожну значущу зміну в базі даних — від входу в систему до виставлення оцінок, що забезпечує прозорість та надійність управління факультетом.

Технологічний стек:
- Frontend/Backend: Python (Streamlit framework).
- Data Processing: Pandas & NumPy для аналізу великих масивів даних.
- Storage: Локальне сховище з підтримкою експорту в універсальні формати (CSV/JSON/XML).

📈 Перспективи розвитку (Roadmap)

У майбутніх оновленнях планується інтеграція з базою даних SQL для постійного зберігання інформації, розширення модулів автоматичної генерації PDF-звітів згідно з державними стандартами та впровадження системи сповіщень через Telegram API.
